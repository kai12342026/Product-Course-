## לקחת הביתה

**שאלות הראיון**
1. תעברי איתי על יום רגיל.
2. מה לוקח לך הכי הרבה זמן?
3. מתי דברים בדרך כלל משתבשים?
4. **ספרי לי על הפעם האחרונה שזה קרה.** ⭐
5. מה את עושה היום כדי להתמודד?
6. מה כבר ניסית?
7. מה יקרה אם לא נפתור את זה?
8. איך תיראה הצלחה?

**המפה**
USER / CONTEXT → PROBLEM → NEED → ASSUMPTIONS → EVIDENCE → OPPORTUNITY → SOLUTION → VALIDATION → IMPACT

> **Don't ask "What can we build?" Ask "What is worth solving?"**
